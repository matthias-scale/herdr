# Compact sections sidebar visual check

1. Set `[ui.sidebar] layout = "sections"` and restart Herdr. The header is plain by default. Set `header = "sky"` separately to check that the sky band and wordmark still appear.
2. In dark and light themes, check Pinned, Active, Snoozed, and Settled in that order. Every shelf has a bare count such as `Pinned 1`. Each agent tab takes one indented row: colored status dot, readable title, pin and lifecycle controls, then idle age or `✓ Done`. A blocked row has a red dot without a label or triangle; the Needs you strip uses dots too.
3. Check that tabs belonging to configured `[[projects]]` appear indented below a project icon, name, and count within each shelf. Unmatched tabs stay directly in the shelf. There are no project letter badges, machine icons, branch lines, or PR lines. Remote hosts display by name as in the current layout.
4. At a normal sidebar width, use the row pin icon to pin and unpin a tab. Check the adjacent snooze and settle actions on a selected tab, then repeat on a different tab. Each action shows a short toast with the tab title and destination shelf. Check unsettle, unsnooze, and the Done check too. At 18 columns, the dot and a useful title fragment take priority.
5. Open the mobile switcher. Check the same indented rows, shelf counts, project groups, and pin target. Confirm scrolling and tab selection still align with the visible rows.
6. Open the `≡` checklist beside the bell and toggle its areas. Check Search, goto-key hint, View bar, host strip, and Notes at 80x24 and 18 columns; the tab list retains at least three rows.
