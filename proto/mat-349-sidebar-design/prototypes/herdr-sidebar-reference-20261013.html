Try the sidebar

Open the interactive prototype. A compact, project-grouped sidebar based on your reference, with instant search and optional provider and machine labels.

This is a separate HTML mockup. It does not connect to your tabs, start agents, or change the installed Herdr.

What to try

ActionExpected behavior
Type in SearchResults update without pressing Enter, including tabs hidden inside collapsed groups.
Open Display optionsTurn provider icons and machine names on independently. Both start off to keep the reference's quiet layout.
Select a tabThe row highlights and the mock detail area changes. Nothing happens to real sessions.
Collapse a project or show moreThe tree changes locally; search still reaches all fixture tabs.

Verification

Headless Chromium passed 20 interaction and layout checks with no uncaught browser errors: instant search, hidden-group results, independent display toggles, unchanged search indexing, keyboard selection, Escape, empty results, reset, reload persistence, and desktop/mobile overflow.

Cmd/Ctrl+K focuses the prototype search field. Herdr's inspected defaults call the native action agent_finder with prefix+f; user-customized bindings may differ. Live transcript matching is simulated on fixture text here.

Scope

The row layout and interactions are the proposal. Native terminal glyphs, actual search integration, live status, and production settings persistence are not implemented by this prototype.
