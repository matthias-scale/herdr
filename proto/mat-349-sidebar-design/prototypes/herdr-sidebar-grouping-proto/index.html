your direction: project first, working hidden

Each project is a folder. Inside it, rows are sorted blocked, then done, then waiting. Working rows are hidden behind a dim ● N working line, and clicking that line opens or closes them for that project only. The header count reads 3 of 5, so you can see how much is still running. A project with only working agents collapses to one dim line at the bottom. The header toggle switches the sort between status and latest activity.

earlier options

My earlier recommendation is a: status first, with no project folders. Blocked, done and waiting are always open and sorted by age; the newest is on top. Each row shows its project as a short dim prefix. Working is one dimmed section at the bottom, collapsed by default; click it to expand. Title markers are a blue dot for working, a green dot for done and ? for waiting.

Why not merge waiting into done (c)? Most ? rows today are detection gaps, such as a parent whose sub-agents are still working. Mixing them into done would make done untrustworthy. Once detection is fixed, c becomes cheap to switch to.
